# Standard Japanese Terms Glossary

This is the **authoritative glossary** for Japanese terms in news articles. When a concept on the left appears in the source news, you MUST use the standard Japanese term in the middle column. The "Wrong variants" column lists forms that LOOK plausible but are NOT standard Japanese — never use these.

These mappings are derived from real errors observed in production. Following this glossary prevents the most common categories of mistakes (wrong ministry names, made-up loanwords, sentiment-mismatched word choices).

## CRITICAL RULE

If the concept in the source matches an entry below:
- **USE** the Standard term exactly
- **NEVER** use the Wrong variants
- **NEVER** invent a new transliteration

If the concept is NOT in this glossary, use your best judgment — but apply the same care.

## Verbs — CRITICAL: subject determines the verb

| Concept | When subject is AI/MACHINE | When subject is HUMAN |
|---|---|---|
| learn / train | 学習する (gakushū suru) | 勉強する (benkyō suru) or 学ぶ (manabu) |
| examine / study (a topic) | 学習する (for AI) | 検討する (kentō suru) for careful examination; 勉強する for general study |
| work | 機能する (kinō suru), 作業する (sagyō suru) | 働く (hataraku) |
| process | 処理する (shori suru) | (humans don't 処理 information) |
| judge / decide | 判断する (handan suru) | 判断する (also OK) or 決定する (kettei suru) |
| think | (machines don't think) — use 処理する or 判断する | 考える (kangaeru) — formal; 思う (omou) — personal feeling |

## Sentiment-Sensitive Words (use context carefully)

| Word | Meaning | Use when |
|---|---|---|
| 問題 (mondai) | problem / issue | Article is genuinely about problems. CORRECT for privacy concerns, GDPR violations, accidents. |
| 課題 (kadai) | challenge / task | Forward-looking problems |
| 事件 (jiken) | incident / case / crime | Negative news: crimes, scandals, tragic accidents. NEVER for positive news (acquisitions, launches). |
| 出来事 (dekigoto) | event / happening | Neutral/positive major events. Use INSTEAD OF jiken for non-crime news. |
| 事故 (jiko) | accident | Implies harm — use only for actual accidents |
| 失敗 (shippai) | failure | — |
| 成功 (seikō) | success | — |
| 成功例 (seikō-rei) | success example / case | News framing positive achievements |

## Proper Nouns vs. Technical Homophones (entity resolution)

Some company/brand names share a reading with a technical term. ALWAYS render the proper noun as katakana or Latin — never as the semantic kanji.

| Reading | Proper noun (use katakana/Latin) | Technical term (only if genuinely meant) |
|---|---|---|
| kyōden | キョーデン / "Kyoden" (the company) | 強電 (high-voltage / heavy-current electronics) |
| (its opposite) | — | 弱電 (jakuden, weak-current / low-voltage electronics) |
| sōnī / sonī | ソニー / "Sony" | — |
| kyanon | キヤノン / "Canon" | 観音 (kannon, Buddhist deity — totally different) |
| daiwa | ダイワ / "Daiwa" | 大和 (Yamato, historical) |
| kōhia | コヒア / "Cohere" | — |

Default rule: if a word in the source is capitalized in English or clearly names an organization/product/person, it is a PROPER NOUN → katakana or Latin, never semantic kanji.

For genuine electronics-engineering articles where high-voltage IS the topic:
- 強電 (kyōden) = high-voltage / heavy-current
- 弱電 (jakuden) = low-voltage / weak-current / signal electronics
- 高電圧 (kōden'atsu) = high voltage (the most explicit term)

## How to use this glossary

1. **As you write each sentence**: scan the concepts you're about to express against this glossary.
2. **If a concept matches**: use the Standard term EXACTLY. Do not generate variants or transliterate yourself.
3. **If the source mentions an entity not in this list**: use your best judgment but err toward the conservative standard term.
4. **When in doubt**: rephrase to avoid the uncertain term.
